## Overview

Seamless Co-op completely overhauls Elden Ring's multiplayer model to allow persistent cooperative play through the entire game — bosses, fog gates, story progression, and all — without the vanilla restrictions of session timeouts and area locks. Up to five players share a session, experience shared world progression, and can be revived by allies, making the full Elden Ring campaign playable cooperatively from start to finish.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Seamless Co-op** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Full Campaign Co-op** | Play the complete Elden Ring story cooperatively from start to finish |
| **Persistent Sessions** | No session timeouts — co-op persists through fog gates and bosses |
| **Shared Progression** | Boss kills and story progression are shared across all co-op players |
| **Player Revival** | Fallen co-op partners can be revived by surviving allies mid-encounter |
